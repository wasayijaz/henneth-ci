# Chrome Web Store submission — v0.3.1

## Upload

1. Open the Chrome Web Store Developer Dashboard.
2. Select **Henneth Desk Companion**.
3. Open **Package** and choose **Upload new package**.
4. Upload `henneth-desk-companion-v0.3.1.zip`.
5. Confirm the manifest version is higher than the currently published version.

## Review before submitting

- Store listing text still describes research only and never placing orders.
- Privacy policy URL: `https://henneth.app/legal/privacy/`
- No new permissions are requested in v0.3.1.
- Host access remains limited to the Henneth API origin plus the supported research sites.
- Privacy practices, single-purpose description, and permission justifications are saved.
- Screenshots and promo assets remain the approved Henneth-branded versions.

## Submit

Save the draft, review the package and listing tabs, then choose **Submit for review**. Existing users remain on the current version until Google approves and publishes the update.
